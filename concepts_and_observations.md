# Assignment 27 — Simple Answers

## Part 1 — Task 1: Understanding Chat Messages

**1. What are SystemMessage, HumanMessage, and AIMessage?**
- **SystemMessage:** Gives the chatbot its role and rules.
- **HumanMessage:** Contains a message written by the user.
- **AIMessage:** Contains a reply generated by the AI.

**2. Why is message-based prompting better than a single prompt?**
It separates instructions, user questions, and AI replies. This makes conversation history easier to manage and helps the model understand context.

## Part 1 — Task 2: MessagePlaceholder Usage

`ChatPromptTemplate` creates a reusable prompt template. `MessagesPlaceholder` is a place where previous conversation messages can be inserted dynamically. In `chatbot.py`, the variable `chat_history` is inserted into the prompt for each question.

Example conversation:
1. User: Explain Python lists.
2. AI: A list stores multiple items in one variable.
3. User: Give an example.
4. AI: `numbers = [1, 2, 3]`

The second question can be understood using the earlier context.

## Part 2 — Task 3: Basic Message History

The program stores messages in a Python list named `history`. After every successful response, it adds a `HumanMessage` and an `AIMessage`. The latest history is sent to the LLM with the next question.

## Part 2 — Task 4: Trimming Chat History

The `trim_history()` function keeps only the latest 10 messages. Older messages are removed when the limit is exceeded. This reduces prompt size and helps prevent token overflow. For a production chatbot, token-based trimming or summarization may be more precise.

## Task 7: Observations and Insights

**1. Why is chat history important?**  
Chat history lets the chatbot remember earlier questions and answers. It can answer follow-up questions without asking the user to repeat information.

**2. Trade-offs between long memory and performance**  
Longer history gives more context, but uses more tokens, can increase cost and response time, and may exceed the model's context limit. Shorter history is faster and cheaper but may lose useful details.

**3. When should we summarize versus trim history?**  
Trim history when only recent messages are needed and a simple solution is enough. Summarize history when older information may still be important, because a summary preserves key facts in fewer tokens.

**4. Difference between message placeholders and memory**  
A `MessagesPlaceholder` is a slot in a prompt where messages are inserted. Memory is the mechanism that stores or retrieves conversation information. The placeholder does not store messages by itself.
